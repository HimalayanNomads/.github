# Security policy

This policy covers every repository in the [HimalayanNomads](https://github.com/HimalayanNomads) organization that doesn't have its own `SECURITY.md`. A project's own policy takes precedence.

## Reporting a vulnerability

Please don't report security problems in public issues, pull requests or discussions.

Open a private security advisory on the affected repository instead: go to its **Security** tab and choose **Report a vulnerability** (`https://github.com/HimalayanNomads/<repository>/security/advisories/new`).

Include:

- Which project and version (or commit) is affected.
- How to reproduce the problem.
- What an attacker could do with it.

The maintainers will reply in the advisory and can credit you when the fix is released, unless you'd rather stay anonymous.

## Supported versions

Unless a project says otherwise, only its latest release and `main` receive security fixes.
